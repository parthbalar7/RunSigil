# Contributor Covenant Code of Conduct

We pledge to make participation in RunSigil a harassment-free experience for
everyone, regardless of identity, background, experience, or ability. Be respectful,
assume good intent while examining evidence rigorously, and accept responsibility
for mistakes.

Unacceptable behavior includes harassment, threats, discriminatory language,
unwelcome sexual attention, deliberate intimidation, and publishing private
information without permission. Maintainers may remove, edit, or reject comments,
commits, code, issues, and other contributions that violate this standard.

Report conduct concerns privately to the contact listed in the repository's
security policy. Maintainers will review reports promptly, protect confidentiality
where possible, and apply proportionate corrective action. This code is adapted
from Contributor Covenant 2.1.
