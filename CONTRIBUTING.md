# Contributing

Thank you for helping build RunSigil. Start with `AGENTS.md`, `ARCHITECTURE.md`, and
the threat model. Open an issue before changing a public protocol, security
invariant, persistence contract, or supported deployment shape.

Contributions must include tests, documentation of user-visible behavior, stable
error codes, and an ADR for consequential decisions. Security-sensitive changes
must describe failure behavior and prove the fail-closed case. Generated success
responses, empty placeholder services, and claims unsupported by executable tests
will not be accepted.

Run `scripts/verify.ps1` before submitting a pull request. By contributing, you
agree that your contribution is licensed under Apache License 2.0.
